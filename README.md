# Travel Website

A modern and responsive travel website designed to help users explore destinations, discover hotels, restaurants, and travel experiences through a clean and user-friendly interface.

## Preview

### Live Website

[View the Travel Website](https://anishams10.github.io/tripadvisor_clone/)

## Features

* Custom travel brand and navigation
* Destination search section
* Featured destination cards
* Hotel, restaurant, and activity listings
* Ratings and descriptions
* Hover effects and interactive elements
* Responsive design for desktop, tablet, and mobile

## Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Media Queries
* Google Fonts

## Design

The website uses an original travel-focused design with visually engaging images, clean typography, card-based layouts, and responsive components.
